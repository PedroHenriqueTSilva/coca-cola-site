# Coca-Cola — O sabor de estar junto

Landing page de portfólio inspirada na identidade visual da Coca-Cola. Conteúdo em português, layout responsivo e interações em JavaScript puro.

## O que está incluído

- Layout para celular, tablet e desktop.
- Menu móvel, navegação entre seções e seletor Original / Sem Açúcar.
- Navegação por teclado, foco visível e respeito à preferência por movimento reduzido.
- Imagens armazenadas no próprio projeto.
- HTML, CSS e JavaScript sem instalação ou etapa de compilação.

## Como abrir

Abra `index.html` no navegador. As fontes do Google Fonts usam internet; se indisponíveis, o site utiliza fontes alternativas do sistema.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie **o conteúdo desta pasta** para a raiz do repositório: `index.html`, `styles.css`, `script.js`, `assets`, `.nojekyll` e este README.
3. Nas configurações do repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta **/ (root)**, e salve.
5. Aguarde o GitHub informar o endereço do site na mesma página.

Os caminhos relativos permitem hospedar em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Personalização

- `index.html`: textos e seções.
- `styles.css`: cores, tipografia, espaçamento e adaptações de tela. As cores principais ficam em `:root`.
- `script.js`: menu e informações do seletor de produtos.
- `assets/`: imagens dos produtos.
